# Интерактивная стереометрия

Модульная учебная web-лаборатория по основам стереометрии. Проект развивает исходную демонстрацию аксиом в полноценный интерактивный курс: ученик исследует условия утверждений, строит доказательства, решает диагностические задания, работает в 3D-песочнице и переходит к пересечениям плоскостей и сечениям многогранников.

## Что реализовано

- 3 аксиомы стереометрии и 3 основных следствия;
- интерактивные Three.js-сцены с вращением, zoom, pan и ортографической проекцией;
- raycasting, выбор и перетаскивание точек;
- контрпримеры и визуальная потеря единственности;
- режим `0 / 1 / ∞ плоскостей`;
- режим `Правда / ложь / недостаточно данных`;
- упражнения `Найдите ошибку`;
- интерактивный proof engine для трёх следствий;
- слой `Почему?` для шагов доказательства;
- 3D-песочница: точки, прямые, плоскости;
- тетраэдр и задача на линию пересечения плоскостей;
- куб и вычисляемое сечение плоскостью;
- рентген, каркас, подписи, сетка, управление уровнем визуальной опоры;
- локальная карта мастерства по 10 диагностическим навыкам;
- учительский режим;
- unit-тесты геометрического и учебного ядра;
- GitHub Actions: typecheck + test + production build.

## Архитектура

```text
UI (React)
   │
   ├── features/
   │     explore / prove / practice / sandbox / mastery / teacher
   │
Learning Core
   │     axioms / consequences / proofs / exercises / mastery
   │
Geometry Core
   │     Vec3 / Line3 / Plane3 / predicates / intersections / constraints
   │
Rendering Adapter
   │
Three.js
```

`geometry-core` не зависит от React и Three.js. Three.js отвечает за визуализацию и picking, а математические определения, пересечения, ограничения и вычисление сечений находятся в собственном доменном слое.

## Запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run typecheck
npm test
npm run build
```

## Структура обучения

Каждый модуль проектируется по цепочке:

```text
наблюдение → эксперимент → контрпример → формулировка → доказательство → задача → диагностика
```

Дальнейшие главы предусмотрены архитектурой: взаимное положение прямых и плоскостей, многогранники, сечения, параллельность, перпендикулярность, углы и расстояния.
